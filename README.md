# Razorpay-buildathon

We are building a two-agent agentic commerce demo on Razorpay's test-mode APIs: a buyer agent that interprets natural-language purchase requests and a seller agent that manages a fixed catalog of 12 products (a small apparel/footwear store), with every proposed purchase passing through a deterministic validator that checks price accuracy, stock availability, and a pre-set spending mandate (max ₹3,000, valid for 24 hours, restricted to catalog SKUs) before any Razorpay Order or Payment Link is created; every agent decision, validation result, and payment outcome is written to an audit log queryable by transaction; and the system explicitly handles one failure scenario end-to-end — a payment that fails or times out after the order is created — by having the buyer agent detect the failure, explain it to the user in plain language, and offer a retry or a suggested alternative, all logged, instead of crashing or falsely reporting success.
